## What this does not prove

- SQLite on one host. A multi-host deployment needs a server database or managed queue with the same lease semantics.
- The provider is a mock that honours idempotency keys. A real provider must be checked to do the same (contract test) before `dispatch` may be pointed at it; the code refuses non-mock providers today.
- Redrive and audit review are protected by a separate reviewer token (see tests/test_adversarial.py), not yet by per-user OIDC identities.
